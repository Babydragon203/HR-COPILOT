# 🤖 HR Copilot AI

**AI-Powered HR Technology Platform**

HR Copilot AI is an AI-powered HR technology platform designed to simplify and support key Human Resource workflows. The project combines **HR domain knowledge with Generative AI and modern web technologies** to assist HR professionals and recruiters with everyday tasks.

The platform is being developed with a focus on the intersection of **Human Resources, Artificial Intelligence, and Technology**.

---

## 🚀 Key Features

### 📄 Job Description Generator

Generate structured and professional job descriptions based on inputs such as:

* Department
* Job role
* Experience level
* Skills
* Job requirements
* Responsibilities

### 🎤 Interview Assistant

An AI-assisted interview preparation and support tool designed to help users prepare for interviews through structured questions and responses.

### 📑 Resume Analyzer

Analyze resumes and provide AI-assisted insights relevant to a job role, helping identify alignment between candidate profiles and job requirements.

### 📊 HR Dashboard

A centralized interface for accessing HR Copilot tools and navigating different HR workflows.

### 🔐 Authentication

User authentication and account-based access to the platform.

---

## 🧠 AI Capabilities

HR Copilot AI uses **Generative AI / Large Language Models (LLMs)** to support HR-related workflows.

The project focuses on using AI for:

* Natural-language generation

## 💻 Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js
* npm
* Git

### Installation

Clone the repository:

```bash
git clone https://github.com/Babydragon203
```

Navigate to the project directory:

```bash
cd hr-copilot-ai
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

The application will be available locally through the development server.
